# Euler Borges Portfolio

Base de portfolio pessoal criada com React, TypeScript e Vite para publicar no GitHub Pages.

## Como rodar

1. Instale as dependencias com `npm install`.
2. Rode o ambiente local com `npm run dev`.
3. Gere a versao de producao com `npm run build`.

## Estrutura

- `src/App.tsx`: landing page principal.
- `src/styles.css`: visual, responsividade e identidade.
- `vite.config.ts`: configuracao do build para GitHub Pages.
